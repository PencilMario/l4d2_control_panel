# L4D2 控制面板前端像素级重设计规格

## 目标

以 `docs/PowerToys_Paste_20260727124901.png` 至 `docs/PowerToys_Paste_20260727125116.png` 七张设计图为桌面端视觉基准，彻底替换现有前端设计。新版保留全部业务能力、API 调用和状态行为，但不保留旧版布局、色板、组件造型、装饰标题或 CSS 兼容层。

## 已确认方案

保留现有 React 业务逻辑、API 客户端和测试契约，重写页面框架、页面 DOM 表达和整套视觉样式。不会为每张截图建立互不关联的页面副本，也不会重写后端或前端业务模型。

## 视觉基准

- 固定约 46px 顶栏和约 200px 左侧导航。
- 主内容区采用接近设计图比例的居中窄幅工作区；总览可使用更宽实例列表。
- 近黑绿色背景、暗绿色 1px 边界、4 至 7px 低圆角。
- 酸绿色表示主要操作与选中状态，青绿色表示成功，琥珀色表示提醒，红色表示危险操作。
- 保持高密度运维界面，不使用营销式留白、插画、渐变、漂浮卡片或大号展示文字。
- 图标、字号、控件高度、间距、边界和信息密度尽量按照设计图比例还原。

## 页面结构

- 总览：顶部摘要指标横排；实例使用可展开的宽面板；主要操作集中在实例标题行；性能指标与历史曲线位于展开区域。
- 私有文件：顶部操作条、左侧目录树、右侧编辑器、底部暂存操作条。
- 内容仓库：页内标签切换共享游戏本体、共享 VPK、插件包和 GitHub 发布源。
- 游戏日志：实例选择和下载操作位于顶部；左侧分类目录；右侧日志预览。
- 后台任务：紧凑筛选条、表格任务列表、行内事件展开和任务日志入口。
- 任务日志：返回入口、标题和动作按钮位于顶部；筛选条下方使用全宽日志区域。
- 游戏控制台：大尺寸居中浮层；顶部实例和连接状态；中部控制台；底部固定命令输入区。

## 共享组件

页面共用顶栏、侧栏、页面标题区、状态徽标、按钮、筛选条、表格、双栏工作区、对话框和日志查看器。共享组件负责维持七张图之间的颜色、尺寸、间距和交互状态一致性。

## 状态与错误

加载、空数据、错误、禁用、执行中和成功状态继续由现有业务状态驱动。状态反馈嵌入设计图已有的页面区域，不新增未在设计语言中出现的页面结构。危险操作继续保留现有确认流程和防重复提交保护。

## 兼容边界

- 后端、API 路径、数据模型、认证方式和业务功能不变。
- 现有自动化测试表达的功能行为必须继续通过。
- 认证页、计划任务和系统设置未出现在参考图中，只使用同一套已确认基础组件适配，不增加新信息架构、新功能或额外设计发挥。
- 移动端仅保证不破版和关键操作可达，不进行独立视觉设计。

## 退役范围

`web/src/styles/app.css` 中旧设计 token、布局规则、装饰性英文样式和旧组件外观全部退役。不得新增旧主题开关、兼容皮肤或新旧 CSS 并存路径。仍被业务逻辑依赖的 class 可以改名或重用，但其视觉定义必须完全归属于新版设计。

## 验证

- 运行前端单元测试和类型检查，确认业务行为与契约不变。
- 运行现有 Playwright E2E 主流程。
- 在参考图对应的桌面视口逐页截图，对照七张 PNG 检查外壳尺寸、内容宽度、组件位置、颜色、间距、文本溢出和弹层构图。
- 检查窄屏不出现不可恢复的导航遮挡、文本覆盖或关键操作不可达。

## 非目标

- 不改后端或 API。
- 不添加设计图之外的新功能。
- 不为未展示页面创造新的信息架构。
- 不保留旧设计痕迹。
