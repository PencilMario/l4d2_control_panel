# L4D2 控制面板运维界面语言重设计

## 目标

保留参考图的暗色高密度运维气质，但不机械复刻草稿。重新设计局部组件和信息组织，彻底去除旧版通用矩形按钮、嵌套卡片、漂浮操作组、不稳定指标网格和重复标题留下的视觉痕迹。

## 已确认方向

采用高密度运维控制台方案。界面安静、明确、适合反复操作；视觉重点来自信息层级、稳定网格和有限的状态色，而不是装饰、渐变、阴影或营销式留白。

## 组件语言

- 工具动作使用 28 至 32px 的图标按钮，依靠图标、tooltip 和 accessible name 表达用途。
- 每个工作区最多一个绿色实心主要动作；普通命令使用低对比描边或文字动作；危险动作使用红色轮廓。
- 状态徽标不再复用按钮外观。
- 页面段落使用连续工作区、边界线和表头，不使用卡片套卡片。
- 表单、标签、筛选器、分页和状态条使用稳定高度和对齐线。
- 所有按钮 hover、focus、disabled、busy 状态属于同一组件语言。

## 页面构图

- 总览：摘要条、实例标题行、单行八项关键指标、独立历史图表。次要存储明细进入 tooltip，不占据指标行。
- 私有文件与游戏日志：顶部工具栏，左侧导航树，右侧编辑/预览，底部状态区；控制不能覆盖内容。
- 内容仓库：标签导航下每次只呈现一个连续数据面，上传操作与列表表头同线。
- 后台任务与任务日志：稳定列宽、独立状态、明确日志入口；展开内容不改变其他行的列定义。
- 控制台与弹窗：统一标题栏、内容区、底部命令/动作区，关闭与危险操作不会抢占主动作。

## 兼容边界

不修改后端、API、请求载荷、数据模型、认证、上传队列、SSE、WebSocket、轮询、确认流程和业务状态。允许重排 DOM 和拆分呈现组件，但现有 accessible command name 与行为测试必须保持。

## 退役范围

旧视觉所有权包括通用 `.card`、`.create`、`.inline-actions`、全尺寸文字工具按钮、嵌套面板和绝对定位操作堆。业务仍需使用的类名可以保留作结构钩子，但不得继续定义旧外观。

## 验收

Vitest、生产构建、Go fixture、桌面/移动 E2E 全部通过。使用 Playwright MCP 在安可服以 1463x800 逐页实拍，检查重叠、错位、文本断裂、按钮层级、工作区边界和滚动行为；远端热部署必须保留回滚副本且不重启游戏容器。
