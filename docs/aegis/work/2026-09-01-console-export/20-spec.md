# 游戏实例控制台文本导出设计

## 目标

在游戏实例控制台页面增加“导出 TXT”操作，将当前前端已显示的控制台文本下载为本地 UTF-8 文本文件。

## 基线事实

- 控制台 UI 由 `web/src/app/App.tsx` 中的 `Terminal` 组件渲染。
- 当前显示内容存储在 `Terminal` 的 `output` 状态中，并受前端 8192 行上限约束。
- 项目已有 `Download` 图标和同类浏览器 Blob 下载实现。
- 控制台标题栏已有“清空显示”按钮，现有工具栏样式可直接复用。

## 交互与数据流

1. 控制台无输出时，“导出 TXT”按钮禁用。
2. 收到输出后按钮启用；点击按钮时以当前 `output` 创建 `text/plain;charset=utf-8` Blob。
3. 通过临时 `<a download>` 触发浏览器本地下载，文件名为 `<实例名称>-console.txt`。
4. 文件名中的 Windows 非法字符、控制字符和末尾空格/点号替换或移除；名称为空时使用 `game-instance-console.txt`。
5. 下载触发后移除临时链接并释放 Object URL；文本不上传服务器。

## 范围与兼容性

- 只修改前端控制台组件和前端测试；不增加 API、数据库字段或服务器文件。
- 导出内容只包含当前页面状态，不读取或导出后端未发送的历史，也不影响控制台连接、跟随、清空和命令发送。
- 保留既有标题栏按钮样式；移动端继续遵循现有工具栏折叠规则。

## 验收标准

- 空控制台时导出按钮不可用。
- 有输出时点击导出会生成 `.txt`，Blob 内容与当前显示文本完全一致。
- 下载文件名包含实例名和 `-console.txt`，非法实例名字符不会出现在文件名中。
- 临时 Object URL 在下载触发后释放。
- 控制台相关前端测试、前端全量测试和生产构建通过。
